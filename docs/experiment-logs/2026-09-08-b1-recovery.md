# Recovery of the historical B1 pattern-map walk

- Date: 2026-09-08
- Goal: resolve the claim that B1 had never run, without losing an existing run
  or misrepresenting a partial-map result as the actual single-seed diagonal.
- Setup: source reviewed against main `372c505` (PR #31).
- Raw artifact: `runs/b1-recovered-2026-09-08/pattern_map_walk32.original.json`.
- Fresh audit: `runs/b1-recovered-2026-09-08/audit.json`.

## Provenance

The JSON and an August 30 log were untracked in the older local checkout at
HEAD `4d251b68a6b4b3b7105b8402cc9e59ff31591e79`. Its dirty script differs from
main only by exhausted-leaf state persistence and a derived conclusion block,
not by the map algorithm. The artifact contains the conclusion block but lacks
leaf states. Its exact producing revision and any postprocessing are unknown.
The raw bytes have been preserved, SHA256
`cfc7f71a06da80d67aeffe0e5bd455a3eed9228cd7bebe4545e27712e88eeb46`.

This is recovery of a historical run, **not** a fresh full trajectory replay
or a successful `workhorse.py` execution. No ledger promotion is made.

## Recorded result and freshly verified subset

The artifact records 36,617,159,481 map steps in 1,582.76 seconds: nine binary
branch points, two doubling leaves, and eight undoubled leaves. Doubling is
recorded on abstract branch `root1` at d=2,107,985,255 and `root00100` at
d=9,958,700,505. The actual diagonal's branch is unresolved.

Reproduce the fresh audit:

```bash
python tools/verify_recovered_b1.py --artifact runs/b1-recovered-2026-09-08/pattern_map_walk32.original.json --self-test --seed-gates
```

The standard-library checks validate all 18 recorded continuations against the
cyclic recurrence, both minimal-period-32 odd-parity event words and their
forced period-64 recurrences, the complete 19-node tree, and the sum of its
edge lengths. Four tampered artifacts (event parity, continuation, step count,
and missing leaf) are rejected.

The optional seed gate uses the existing NumPy/Numba implementation to rerun
the 200,000-diagonal simulation. It reproduces seed d0=88,867, words
`0x761f998d`, `0x0c9b5379`, the histogram, and base row. Both 50,000-diagonal
gates pass with zero violations/mismatches. These are finite simulation checks,
not a proof that the measured tails remain settled forever.

The audit does **not** independently check the billions of transitions between
recorded branch nodes. Internally consistent event data is not a trajectory
certificate. The full reproduction command remains:

```bash
python experiments/pattern_map_walk.py --max-d 12000000000 --pretty
```

Use a separate output path to preserve the recovered raw artifact.

## Two metadata cautions

`max_d` is exclusive: an exhausted leaf's `reached_d=12000000000` is the next
unprocessed diagonal. Report absence of an encountered doubling **below**
that boundary, not an inclusive assertion at it.

The event field `collision_pair=[d-2,d-1]` names the input `(u,0)`; it is not
the equal-word pair. The equal pair is `[d-3,d-2]`, producing zero at d-1.
The recovered artifact is left unchanged; the verifier labels this explicitly.

## Interpretation and next step

The cheap hoped-for outcome, doubling on every abstract branch within the
recorded horizon, was not obtained. Neither event proves a 32-to-64 transition
on the actual diagonal. The useful next mathematical target is the transient
condition selecting a continuation at the first branch point, d=1,420,878,969.
Extending the recovered tree requires replay because its leaf words are absent.
This left-edge work is not progress on the center-column prizes.
