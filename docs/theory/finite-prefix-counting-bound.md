# The Finite-Prefix Counting Bound

**Read this before running any "we searched model class M and found no fit"
experiment.** It is the single cheapest way to avoid burning GPU-months on a
result that was arithmetically guaranteed before the run started.

## The bound

Let `M` be a class of candidate shortcuts, each of which deterministically
predicts every bit of a binary sequence. Let `|M|` be the number of *distinct
behaviours* in the class. Counting syntactic descriptions instead is fine for a
vacuity verdict (it can only overstate `|M|`); see "Mind the direction" below
before quotienting by symmetries.

Test `M` against the first `n` bits of a sequence. A fixed member of `M` matches
a uniformly random binary sequence of length `n` with probability `2^-n`. By the
union bound,

```
E[# members of M that fit n random bits]  =  |M| · 2^-n
P[some member of M fits n random bits]    <=  |M| · 2^-n
```

So:

> **A negative result ("nothing in `M` fits the first `n` bits") carries
> information about the sequence only when `log2 |M| >= n`.**
>
> When `log2 |M| << n`, *every* sequence produces that negative — a random one,
> a structured one, the digits of pi. The experiment has measured `|M|`, not the
> sequence.

The useful quantity is never a single yes/no at one `(|M|, n)` point. It is the
**complexity curve**: the minimal-size member of `M` that fits the first `n`
bits, as a function of `n`, plotted against the counting-null curve
`log2 |M(size)| = n`.

## Worked case 1 — GF(2) linear recurrences (this repo's Experiment S). SOUND.

An LFSR of order `L` is pinned by its feedback polynomial: `2^L` behaviours once
the first `L` bits are fixed as state. Expected fits on `n` bits:
`2^L · 2^-(n-L) = 2^(2L-n)`. Informative iff `L >= n/2`.

`docs/experiment-logs/S_linear_complexity.md` measured `L(n) = n/2` exactly at
n = 4k, 8k, 16k, 32k. That is simultaneously the **maximum possible** linear
complexity and **exactly the counting threshold**. Experiment S is therefore a
correctly-designed, non-vacuous negative. It is the template.

## Worked case 2 — DFAO / automatic sequences. THE 2026-06 RESULT WAS VACUOUS.

A binary-output DFAO with `s` states over base-`b` digits and a fixed initial
state is described by `s^(s·b)` transition tables and `2^s` output labelings:

```
|M(s,b)|  <=  s^(s·b) · 2^s                       (UPPER bound)
|M(s,b)|  >=  s^(s·b) · 2^s / (s-1)!              (LOWER bound)
```

**Mind the direction.** The `(s-1)!` quotient by relabelings of the non-initial
states gives a *lower* bound, not an upper one: by Burnside the number of orbits
is at least `|X|/|G|`, and automata with nontrivial stabilizers have short orbits
that only push the orbit count up. So:

- for a **vacuity verdict** use the **upper** bound — overstating `|M|` makes the
  "this was guaranteed" claim conservative;
- for a **fair-threshold** question use the **lower** bound — understating `|M|`
  demands more states and is conservative in that direction.

For `b = 2`, using the upper bound:

| s | log2\|M\| | max informative n |
|---|---|---|
| 4 | 20.0 | 20 |
| 5 | 28.2 | 28 |
| 6 | 37.0 | 37 |
| 8 | 56.0 | 56 |
| 10 | 76.4 | 76 |
| 12 | 98.0 | 98 |
| 14 | 120.6 | 120 |
| 15 | 132.2 | 132 |
| 16 | 144.0 | 144 |
| 18 | 168.1 | 168 |
| 20 | 192.9 | 192 |

### The verdict

`docs/CLAIM_LEDGER.md` recorded, at level **Certificate**:

> "The first 128 center-column bits are not generated by any 1-4 state binary
> DFAO in MSD or LSD digit order."

and `docs/experiment-logs/2026-06-15-prize-frontier.md` extended it to 1-5
states. Applying the bound:

```
s <= 5, n = 128:   E[# fits] <= 2^(28.2 - 128) = 2^-99.8
```

A random sequence produces the identical negative with probability
`1 - 2^-99.8`. **This is not a certificate about Rule 30. It is a restatement
of the fact that there are only about 3x10^8 5-state binary DFAOs.**

The run's own data said so and it was not acted on: the seeded-random baseline
returned the *same* negative at every prefix and both digit directions. That
agreement was the tell, and it was logged as "expected" rather than as a
refutation of the experiment's design.

The planned next step — pushing to states 6-8 at n = 128 — is still vacuous by
`2^-72`. The SAT frontier of 32 CNFs generated for states 5-8 at n = 128/256
will return UNSAT, correctly, and mean nothing.

### The fair thresholds

To make a DFAO negative at prefix length `n` non-vacuous you need:

| n bits | states required (optimistic .. conservative) |
|---|---|
| 64 | 9 .. 11 |
| 128 | 15 .. 20 |
| 256 | 25 .. 34 |
| 512 | 44 .. 61 |

Exhaustive search is hopeless at every one of these. The tractable direction is
the other one: **fix a small `s`, and ask for the largest `n` it can fit** —
i.e. measure the curve `s*(n)`, the minimal state count fitting the first `n`
bits, in the regime `n ~ log2|M(s)|` where SAT is feasible (`n` of order tens,
`s` of order 4-12). Compare against:

- **counting null** — the `s` where `log2|M(s,2)| = n` (table above);
- **empirical random control** — same measurement on a seeded random sequence;
- **positive control** — Thue-Morse, which is genuinely 2-automatic and must
  come back with `s* = 2` at every `n`, proving the method can see a real
  shortcut when one exists.

Signal would be Rule 30's `s*(n)` sitting **below** the random/counting curve.
Tracking it is a quantified negative, which is a real result. That experiment is
`docs/experiment-logs/2026-08-15-dfao-min-state-curve.md`.

## The general discipline

Before proposing a search over a model class, state three numbers:

1. `log2 |M|` for the largest class you will search.
2. `n`, the prefix length you will test against.
3. The difference. **If `log2|M| - n` is very negative, do not run it.**

And prefer a *curve against a null* to a *point against nothing*.
