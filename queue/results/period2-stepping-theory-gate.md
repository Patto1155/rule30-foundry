## Standing-rule application

**Prize object.** B–E study a general finite-row lemma that, if proved, applies to the prize seed. Their reported numerical curves are bounded findings. Keep the distinction explicit (`README.md` §0; log SAT replay).

**Counting.** Before any model search returning “no fit,” record the actual model class, cardinality, fitted data length and counting-bound verdict (`README.md` §§2,6). For onset-zero nonzero finite rows in [-R,R], use `|M|=2^(2R+1)-1` against L target bits, as in the existing period-ladder log. A sparse-class UNSAT result is still an exact finite exclusion, but cannot serve as evidence of exceptional complexity. For recurrence, holonomic or k-regular fitting, specify coefficient/state/order bounds and run counting before negative conclusions. Continuous unbounded parameter classes cannot be assigned a finite count without a declared bounded encoding. No-fit outcomes from heuristic guessers are only failures of those searches, never mathematical nonexistence.

**Controls and null.** Reproduce existing constant-trace fibers and horizons, compare reconstructed left prefixes against an independent truth-table forward simulation, and use held-out depths/right halves to test fitted predictions. Random target traces can calibrate instruments, but neither random-row averages nor matched random slopes prove a deterministic support theorem (`README.md` §§0,6; theoretical-reframe diagnosis).

**Zero-control correction.** Constant-zero target has linear forced-tail growth only when the initial positive half is nonzero. For `r=0`, its unique completion is identically zero: this must be a deliberate zero-weight control, not an instrument failure (`period2_attempt.md` §2, Zero fiber existence). Any period-one exclusion additionally requires a nonzero finite row. Alternation itself excludes the zero orbit through its target hypothesis.

**Rule90 filter.** Every argument must identify use of Rule30's OR/reset rather than left permutivity alone (`README.md` §4 right-special row; `period2_attempt.md` opening filters). The Rule90 single-cell constant-zero tail and the two-cell seed at -1,+1 constant-zero trace are explicit existing countercontrols. An instrument should reproduce their finite-completion behavior; do not assume the Rule90 alternating target automatically has a zero-density completion. A calculation about a different target is not the requested separating argument.

**Quantifier correction.** The target is `forall r>=0 exists alpha(r)>0,C(r)<infinity forall N>=1: W_N(r)>=alpha(r)N-C(r)` (`period2_attempt.md` §5). One long low-slope prefix does not refute this statement: both constants may depend on r, and C can absorb every finite prefix. A single prefix can kill a separately stated explicit bound (fixed alpha,C), bounded-gap assertion or finite combinatorial lemma. A slow row should be flagged as an adversarial lead, not a proved counterexample or an infinite alternating finite row. An infinite zero-density completion would refute density while leaving period-two exclusion intact. Uniform alpha across all r is an additional unsupported strengthening.

**Promotion.** Exact finite reconstruction/enumeration yields bounded results with replayable witnesses; horizon minima need SAT witnesses plus verified UNSAT proof evidence; conjectures need precise survivor/untested distinctions. A killed universal finite-checkable candidate needs one exact witness. An asymptotic existential candidate without a finite falsifier must remain untested, even if its finite data look favorable (`README.md` §6; `period2_attempt.md` §5).
