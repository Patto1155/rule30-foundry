# verify_all stage reaches the same verdict. Adding packages CI does not need

# finding, not a reason to widen this file silently: tests/test_import_safety.py
# exists because a missing optional dependency once deleted 23 tests without
# reporting a single failure. Add the package here AND say why.
#
# Not here on purpose:
#   cupy, torch, numba  - GPU only; CI has no GPU and must not pretend to.
#   pysat               - guarded; its absence skips no test (verified above).
#   scipy, matplotlib   - used by individual experiments, not by any CI stage.
